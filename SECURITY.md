# Security policy

## Scope

This policy covers vulnerabilities **in wraith itself** (the scanner) — not
findings produced by running it against other systems.

## Reporting

Report privately via GitHub Security Advisories ("Report a vulnerability" on the
repository's Security tab), or open a minimal issue if it is not sensitive.
Please include a description, affected version (`wraith --version`) and steps to
reproduce. Expect an initial response within a few days.

## Responsible use

wraith is offensive tooling. Only run it against systems you are permitted to
test. Misuse is the operator's responsibility, not the project's.
